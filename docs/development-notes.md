# Village Architect（村民建筑师）

Minecraft **1.21.1 / Fabric** 的服务端模组：让**没绑定床的成年村民**自己去找空地、招呼石匠、然后从原版村庄结构里掏一座房子盖出来；在村外露天床上睡觉的村民睡醒后还会跑来送你 8 颗绿宝石。

- **纯服务端**：服务器（或单人世界的集成服务端）装上就能用，客户端不用装、也不用装 Fabric API 以外的任何东西。
- **不用 mixin**：村民是 Brain AI 不是 GoalSelector，所以模组走 `ServerTickEvents.END_SERVER_TICK` 驱动，兼容性最好。
- 模组 id：`villagearchitect`，jar 名：`villagearchitect-1.1.0.jar`

---

## 一、安装

### 单人世界
把 `villagearchitect-1.1.0.jar` 丢进**这个版本自己的 mods 目录**。你的 PCL 开了版本隔离，路径是：

```
C:\Users\31896\Desktop\.minecraft\versions\1.21.1-Fabric 0.19.5\mods\
```

（不要放 `Desktop\.minecraft\mods\`，开了版本隔离那里不会加载。）
同时该版本必须已经有 **Fabric API**（`fabric-api-0.116.17+1.21.1.jar`，你本来就有）。

### 服务器（wandou.cab 这种）
把 jar 上传到服务器的 `mods/`，重启服务器即可。服务器需要 Fabric Loader + Fabric API，版本 1.21.1。
**客户端什么都不用装**，原版客户端照样能进服看到村民盖房子。

## 二、它会做什么

### 建房条件（对应你提的 4 条）
| 你的要求 | 模组里的实现 |
|---|---|
| ≥2 个没绑定床的村民，且只有未绑床的村民能建房 | 只有 `HOME` 记忆为空的村民才会进入"找地"状态；必须**同一片 16 格内有另一个同样就位的未绑床村民**才会动工 |
| 必须开阔空间，室内不行（16×16×16） | 以 16×16 为footprint 找地：地面高差 ≤1、上方 16 格全是空气，且头顶 16 格内没有实心方块（露天） |
| 只能是成年村民 | 小村民直接跳过 |
| 建房村民 8×8 格内必须有石匠 | 动工前检查该村民 8 格内是否有一名 `minecraft:mason` |

### AI 补充（对应你提的 4 条）
1. **自动找空地**：没绑床的村民每 10 tick 检查一次，自己搜索 20 格内合适的 16×16 平地，找到就自己走过去。
2. **吸引石匠**：村民**一进入"要建房"状态（选中空地、开始赶路）就把石匠叫过来**，不是等到站定才叫；石匠会一路跟着这名村民走到工地（距离超过 8 格就重新朝村民寻路）。
3. **一对一**：每个村民最多占用一名石匠，其他村民不会抢同一个石匠。
4. **送绿宝石**：村民在**露天**（上方 16 格无遮挡，也就是"村庄房子外面"）绑了床、并且睡过一觉后，会寻路到 8 格内最近的玩家，塞给他 **8 颗绿宝石**；每只村民一生只送一次（用命令标签 `va_gifted` 持久化，重启服务器也不会重复送）。

### 房子盖好后
结构放完后模组会**自动清理模板里带出来的辅助方块**：
- `minecraft:jigsaw`（紫黑色的拼图方块，原版靠它拼接村庄，手动放置后会留在门口/墙里）
- `minecraft:structure_void`（看不见的结构空位方块）
- `minecraft:structure_block`（如果有）

清理范围以房子原点为中心、水平 ±17 格、竖直从地面向上 `size.y` 格，只替换上面这三种方块，其它方块一律不动。

### 简单互动
**潜行 + 右键**村民 → 聊天栏告诉你它现在在干嘛：
- 「这是一只小村民，长大后才会参与建筑」
- 「已绑定床，不会去盖房子」
- 「还没找到合适的空地」
- 「正在前往空地 x, y, z」
- 「已就位，附近就位村民 N 名、石匠 M 名」+ 还差哪个条件（差村民 / 差石匠 / 条件满足马上开工）

## 三、配置文件

首次启动后生成 `config/villagearchitect.json`（单人世界在 `versions\1.21.1-Fabric 0.19.5\config\`）：

```json
{
  "intervalTicks": 10,
  "villagerScanRadius": 48,
  "searchRadius": 20,
  "openSpaceSize": 16,
  "buildClusterRadius": 16,
  "masonRadius": 8,
  "attractRadius": 24,
  "giftRadius": 8,
  "giftAmount": 8,
  "searchCooldownTicks": 400,
  "buildCooldownTicks": 6000,
  "enableBuilding": true,
  "enableMasonAttraction": true,
  "enableGifts": true
}
```

- `searchRadius`：找空地的半径（嫌村民乱跑就调小）。
- `buildClusterRadius`：两个村民要多近才算"一起盖"（默认 16）。
- `buildCooldownTicks`：同一地点盖完后的冷却，防止在同一块地反复盖（默认 6000 tick = 5 分钟）。
- `giftAmount`：送几颗绿宝石。
- 三个 `enable*`：分别关掉建房 / 石匠吸引 / 送绿宝石。

改完配置要**重启服务器或重进世界**才生效（配置在启动时读一次）。

## 四、怎么快速测试

1. 创造模式，找一片平地（平原生物群系最好，房子会按生物群系选样式）。
2. 在空地边上生成 2 个普通村民：
   ```
   /summon minecraft:villager ~ ~ ~
   /summon minecraft:villager ~ ~ ~
   ```
3. 再生成 1 个石匠：
   ```
   /summon minecraft:villager ~ ~ ~ {VillagerData:{profession:"minecraft:mason",level:1,type:"minecraft:plains"}}
   ```
   （如果这条 1.21.1 语法报错，就放一个切石机在旁边，给村民转职成石匠。）
4. 站远一点看：村民会自己走向一片 16×16 的平地站定，石匠跟过去，然后「咚」地出现一座原版村庄房子。
5. 中途可以**潜行 + 右键**村民，看它还差什么条件。

测送绿宝石：在**露天**放一张床，晚上让村民在旁边睡一觉（绑床），睡醒后它就会跑到你面前塞 8 颗绿宝石（聊天栏有提示）。

## 五、已知限制

- **房子可能和地形/其它建筑重叠**：只在 16×16 footprint 上检查了平整度和净空（每 2 格采样一次，1.2.0 起更密），没有做"周围是否已有房屋"的完整检测；建房冷却默认已关闭。
- **清理范围**：以房子原点为中心水平 ±17 格的立方区域里，所有 `jigsaw` / `structure_void` / `structure_block` 都会被换成空气。如果附近正好有你自己放的拼图方块，也会被清掉。
- **村民被玩家吸引**：原版村民有"靠近玩家打招呼"的行为，可能偶尔打断寻路；模组每 10 tick 重发一次寻路指令，一般能自愈。
- **不检测村庄边界**：只按"床的上方是否露天"判断是否在村外，符合你说的"村庄结构建筑之外"的直观含义。
- **房子不会生成村民/床**：只放结构方块，`setIgnoreEntities(false)` 但村庄房屋模板本身不含实体，所以不会凭空多出村民。
- 本模组**无法在开发机上实机验证**（沙箱限制），已经做了静态校验：`Verify checked refs=210`、无缺失符号，结构 id 全部对着 `1.21.1.jar` 里的 `data/minecraft/structure/village/*` 逐个核对过。

## 六、1.1.0 改了什么

1. **房子盖好后清理结构方块**：`jigsaw`、`structure_void`、`structure_block` 全部换成空气，不再在门口/墙里留下紫黑色的拼图方块。
2. **石匠更早被吸引**：村民一选中空地、开始赶路，就把石匠叫上；石匠会一路跟到工地，而不是等村民站定才动身。

> 1.0.0 已经盖出来的老房子不会自动补清理，用命令手动清一下就行（把坐标换成房子范围）：
> ```
> /fill x1 y1 z1 x2 y2 z2 minecraft:air replace minecraft:jigsaw
> /fill x1 y1 z1 x2 y2 z2 minecraft:air replace minecraft:structure_void
> ```

## 七、1.2.0 改了什么（解决"一堆村民只建了一间房"）

1. **建房冷却默认改成 0**：`buildCooldownTicks: 0`。旧版建完一间后会把周围 8 格内的空地全部标记 5 分钟，村民就傻站着不动了；现在没有冷却。
2. **石匠建完立刻找下一个**：房子落成后石匠被释放，下一个 tick 就会走向附近"已选好空地、还没房"的村民（`attractRadius` 内最近的），不再有等待。
3. **石匠会被自动指派**：空闲石匠找到目标村民时会直接登记配对（以前只跟过去不登记，导致永远凑不齐"石匠在 8 格内"的条件）。
4. **找不到空地会走开再找**：搜索失败的村民会朝"离最近新房子更远"的随机方向走 14~26 格（每 8 秒一次），不会围着一间房打转。
5. **空地复核**：真正放房子前会再检查一次 16×16 是否仍然空着；如果被刚建好的房子占了，就放弃这个点、重新找，不会把新房子盖进旧房子里。
6. **新房子落成时清空附近的候选点**：14 格内其它村民已选的空地全部作废并立即重新搜索。

配置里 `buildCooldownTicks` 如果还是 6000，改回 0 就能一直建；`searchCooldownTicks` 控制搜索失败后多久重试（默认 400 tick = 20 秒，失败时另有 120 tick 的快速重试）。

> 注意：同时满足"2 个未绑床的成年村民 + 8 格内有石匠 + 16×16 平地"时才会建。如果一个村里只有 1 名石匠，那它一次只能带一对村民盖一间，盖完接着下一对——这正是现在的行为。想更快就多招几个石匠（切石机旁边放村民）。

## 八、1.3.0 改了什么（房子之间至少隔 2 格）

1. **记录每一间自己盖的房子**：新房子落成时把它的立方体范围（min/max XYZ）记下来，存到 `config/villagearchitect-houses.json`（按维度分组，重启不丢）。
2. **强制最小间距**：新房子放下去之前，会把它的范围向四周各外扩 `minHouseGap`（默认 2）格，只要和任何一间已记录的房子相交，就换下一个模板；六个模板都放不下就放弃这个点、让村民重新找地。所以两间房的墙之间**正好留出 2 格空气**（配置成 0 就是允许贴在一起）。
3. **搜索阶段就避开**：`findOpenSpaceNear` 也会拿 16×16 足迹去比对已建房子，村民不会一直往同一间房旁边凑。
4. **不会覆盖已有建筑**：放房子前会检查模板体积内是否已经站着实心方块（原版村庄房子、玩家建筑、大树都算），有就不放——这条对 1.3.0 之前盖的老房子同样有效（老房子没进记录表，但它的墙会挡住新房子）。

> 老房子（1.2.0 及以前盖的）不在记录文件里，所以它们周围的间距是"靠墙挡住"实现的，不是精确 2 格；从 1.3.0 开始盖的房子之间都是精确 2 格。想让记录归零直接删 `config/villagearchitect-houses.json` 即可。

## 九、1.4.0 改了什么（补墙洞、扩大间距检查、去掉泥土底）

1. **补上墙上的洞**：原版房子模板里留着给世界生成用的 `jigsaw` 方块，它们经常正好嵌在墙中间。1.1.0～1.3.0 是直接把这些方块删掉，于是墙上会缺一两个方块。现在改成**用四周最常见的墙材把它补回去**（六面邻居里出现最多的实心方块；四面都是空气时才留空），同时在模板的精确范围内扫描，不再往外扩，避免误伤房子旁边的玩家方块。
2. **间距检查更强**：除了比对已记录的房子，放房子前还会把房子范围向外扩 `minHouseGap` 格，逐格检查这一圈里有没有**任何实心方块**（老房子、玩家建筑、树都算）。有就换模板、换地点。所以"2 格空气"现在是结构性保证，连 1.3.0 之前的老房子也照顾到了。
3. **去掉泥土底**：模板最底下一层通常是泥土/砂土，铺在草地上就是房子底下一圈棕色。现在把这一层的泥土类方块**替换成房子周围的地面方块**（平原就是草方块，沙漠是沙子）——地面高度不变，房子不下沉也不悬空，只是不再有那圈土。
4. **旋转后的占地修正**：房子随机转 90°/270° 时，长宽会互换；之前算的立方体范围还是按没转的长宽算的，间距/记录会偏。现在按旋转后的实际长宽计算落点和记录范围，间距更准。

> 已经在世界里的老房子不会自我修复（墙洞、土底都留在原地）。想清掉旧痕迹：墙洞手动补，土底用 `/fill x1 y1 z1 x2 y2 z2 minecraft:grass_block` 之类覆盖即可。

## 十、1.5.0 改了什么（压到地面层 + 结构方块清零）

1. **房子最低层压在"地面那一层"**：以前放房子时，基准点取的是地面上方那一格（地形的草坪之上），于是房子整体比地面高一格，底层泥土就在草地上摊成一圈"台子"。现在基准点改成 y = 地面方块 y，房子最底层**和地面层重叠**：落位时模板里那一层的方块（地板、墙脚、台阶）会直接覆盖掉同位置的地形方块，屋子里外的地面高度齐平，不用再跨一格台阶。
2. **结构方块彻底清干净**：之前只扫模板自身的立方体范围，但房子会随机旋转 90°/180°/270°，旋转是绕落点转的，jigsaw 会被甩到"未旋转体积"之外——这就是"有的房子有结构方块、有的没有"。现在额外扫一圈外扩 max(长, 宽)+2 的区域，把外面那一圈里的 jigsaw 也找出来补掉；structure_void / structure_block 同样清成空气。
3. **泥土层换成地面方块**：底层重叠到地形后，模板自带的泥土/砂土会盖住本来那层草。现在把这一层里的泥土类方块替换成房子周围最常见的地面方块（平原→草方块，沙漠→沙子），和村子别处的地面一致。

> 已在世界里的老房子依然不会自愈（高出一格的台子、残留的紫色 jigsaw 都还在）。清理老房子：/fill x1 y1 z1 x2 y2 z2 minecraft:air replace minecraft:jigsaw，台子用 /fill 换成 minecraft:grass_block 再在边缘放草方块即可。

## 十一、1.6.0 改了什么（补上地面被挖成空气的坑）

问题：1.5.0 把房子底层压到地面层之后，模板最底层里**没有方块的位置（模板写的是空气）**也会覆盖地形——那些位置本来是草地，被写成了空气，于是房子四周出现一圈一格深的沟、边角出现方坑。

修法：房子放完以后，把底层这一层（y = 地面 y）逐格检查一遍——
- 是泥土/砂土 → 换成房子周围的地面方块（草/沙）；
- 是空气、且正下方还是实心地面 → **填回地面方块**（草方块/沙子）。

所以现在不会再出现沟和坑，屋里屋外都是同一层地面。
## 十二、2.0.0 改了什么（改用你给的那套建筑 + 四角检测）

这一版把命令方块原型里的做法搬进了模组：

1. **建筑换成你做的那些**：`house`、`big_house`、`large_house`、`workshop`、`big_workshop`、`shop`、`camp`、`big_camp`、`farm` 九个结构已经打包进模组（`data/villagearchitect/structure/*.nbt`），随机按权重挑一个来盖，和原型里 `place template` 用同一批房子。找不到这些结构时自动退回原版村庄小屋。
2. **四角检测**：找地不再采样 16×16×16 的整块体积，而是像原型那样检查**四个角 + 四条边中点 + 中心**这 9 个点——必须高度一致、脚下是天然地面（草/土/沙/石等），并且这 9 列从地面往上一直到建筑高度都不能有实心方块。
3. **不旋转**：原型的 `place template` 从不旋转，2.0.0 也一样。落点偏移固定为 `(站点 - (宽-1)/2, 地面层, 站点 - (深-1)/2)`，底层正好压在草地那一层。
4. **施工时间**：两名村民和石匠在工地上站 `buildDelayTicks`（默认 60 tick = 3 秒）之后房子才落成，不会"人一到房子立刻就出现"。
5. **落成后清场**：房子一放下，就把可能被埋进墙里的建造村民和石匠挪到房子外的空地上，不会卡在墙里。
6. 结构里的命令方块、`copper_golem_statue` 这类 1.21.1 没有的东西已经全部处理掉；结构文件从 `DataVersion 4790` 降到 `3955`。

新的配置项：

```json
"buildDelayTicks": 60
```

`center`（广场）结构也一起打包了，但目前不进入随机建造列表。

## 十三、2.1.0 改了什么（改回原版建筑，还是原版村庄小屋）

2.0.0 用的是你给的那套自制建筑。这一版按你的要求改回去了：**只用原版村庄小屋**，也就是游戏自己生成村庄时用的那批 `minecraft:village/<群系>/houses/*`，平原、沙漠、热带草原、雪原、针叶林各一套（小房、中房、大房、图书馆、石匠屋）。模组里不再打包任何自制结构，jar 从 60KB 缩到 30KB。

同时保留了 2.0.0 里那几个真正解决问题的改动：

1. **四角检测找地**：不再是"16×16×16 体积里没方块"那种粗暴判断，而是像你做的那套命令方块一样，检查**四角 + 四边中点 + 中心**这 9 个点——高度必须一致、脚下必须是天然地面（草/土/沙/雪/石等），并且这 9 列从地面往上到房子高度都不能有实心方块。脚下不是草地、或者地面有坡，这个点就被否掉，村民不会站在那里硬盖。
2. **不再随机旋转**：上一版（1.6.0）房子会随机转 90°/180°/270°，但模板旋转是绕着落点转的，转 90° 之后房子会整体偏出去半个房宽——这就是你之前截图里"两栋房子错位、几乎贴在一起"的根源。现在统一不旋转，落点固定在 `(阵地 X - (长-1)/2, 地面层, 阵地 Z - (宽-1)/2)`，房子正好压在检查过的那 9 个点上。
3. **施工时间**：两个没绑床的成年村民 + 一位石匠在阵地上站满 `buildDelayTicks`（默认 60 tick = 3 秒）后房子才落成，不再是"人一到房子立刻出现"。
4. **落成后清场**：房子一放下，就把可能被埋进墙里的建造村民和石匠挪到房子外的空地上，不会卡在墙里。
5. 仍然保留：补墙洞（jigsaw 用四周最多的墙材填回）、房子之间至少隔 2 格（`minHouseGap`）、底层泥土换成本地地面方块、下沉造成的坑填回草方块。

一句话概括：**建筑回到原版，找地和防重叠用你命令方块原型里那套四角检测，落地不再旋转。**

想再换成别的模板，改 `StructurePlacer.java` 里的 `HOUSES` 表即可；想调房子大小上限，改 `pick()` 里的 `size <= 16`。

## 十四、2.1.1 改了什么（村民被顶到屋顶）

不是你村民太多，是代码顺序写错了，这是必现问题，人少也一样：

- 旧流程是 **先盖房子，再把村民挪出去**。方块一落下来，站在原地的村民就被墙体和地板往上顶，直接站到屋顶上；之后那段"找空地挪人"的代码又是从 `房子最高点+1` 往下找地面，**第一个找到的实心方块就是屋顶**，于是把它自己放到了屋顶上，等于没救。
- 新流程反过来：**先把人要出来，再盖房子**。落成前先把整个占地范围算出来（`StructurePlacer.boxOf`），把站在范围内（包括已经站在屋顶上）的村民走到房子外侧一格以外的空地站好，然后才 `place`。盖完又用实际占位再扫一遍做保险，确保没人被圈在墙里。
- 以后新房子不会再出现"房顶站着人"；已经发生的老情况，下次房子盖在附近时也会被顺带挪下来。

所以这条既不是村民数量问题，也不是随机 bug，是"先建后挪"的顺序问题，2.1.1 已经改成"先挪后建"。

## 十五、2.2.0 改了什么（两间住房换一栋职业房子）

### 规则

- 每**两间普通住房**建好之后，村里会再建**一栋随机职业的房子**（图书馆、石匠屋、屠夫铺、制图师、渔夫小屋、制箭师、牧羊人屋、盔甲匠、工具匠、武器匠、制革屋——按当前群系随机抽一个）。
- 这两间住房和这栋职业房子**绑定**成一组，记在 `config/villagearchitect-houses.json` 里（每栋房子多存一个类型字段：0 普通未绑定、1 普通已绑定、2 职业房）。
- **已经绑定过的两间不会再被拿去配职业房**，也不会再生成新的绑定；所以配对只会往前走，不会重复。
- 职业房子附近会优先出现在这两间房子的中间地带（取两栋房子的中心点去找空地），而不是随便找地方。

### 怎么触发

不用你手动点：只要有两位没绑床的成年村民 + 一位石匠在干活，等到村里出现**第一组尚未配对的住房**，下一次盖房子就自动变成"随机职业房子"，盖完立刻把这两间标成已绑定。下一组再出现时，重复同一套。

### 和之前版本的兼容

老存档里已有的房子会被当成"普通未绑定住房"（旧记录只有 6 个数字，读进来默认类型 0），所以升级到 2.2.0 之后，已有的房子也会参与配对——第一次配对会用最早建的两栋。

### 配置

没有新增配置项。想临时关掉这个规则，把 `enableBuilding` 设成 `false` 即可（整条建房线一起停）。

## 十六、2.2.1 改了什么（不建房怎么查）

1. **修掉"职业房找不到地方就整体卡住"**：2.2.0 里只要存在待配对的两间房，找地中心就固定死在那两栋房子的中间点，半径 20 格内塞不下就**永远找不到地**，于是一栋都不盖。现在按顺序试：两栋中间 → 村民脚下 → 实在不行先盖普通房，配对留着下次再试。
2. **新增诊断命令** `/villagearchitect status`（需要 OP/权限等级 2），会打印：
   - 已记录的建筑数量（未配对住房 / 已配对 / 职业房）
   - 下一栋会盖哪一种、待配对的是哪两栋
   - 附近 32 格村民总数、成年数、其中没绑床的数量、石匠数量
   - 正在张罗的村民数量（找地中 / 已就位 / 已配石匠）
   - 建成条件的具体数值

   不建房时先跑这个，基本一眼能看出卡在哪一步。

### 不建房的常见原因（按出现频率）

| 现象 | 原因 | 处理 |
|---|---|---|
| 村民到处走但从不站定 | 附近真的没有"16×16 全平 + 9 个采样点同高"的空地 | 找一片平地，或者把 `openSpaceSize` 调到 12 |
| 状态显示"已就位"但没有第二个人 | 另一位村民没站到 16 格内，或它的石匠不在 8 格内 | 多放几个村民，把石匠带到旁边 |
| 附近村民很多但"没绑床"是 0 | 村民都抢了房子里的床（有床就不参与建房） | 拆掉多余床，或者把村民带到没有床的地方 |
| 只有小村民在动 | 小村民不参与建房 | 等长大，或换成年村民 |
| 状态里一栋建筑都没记录 | 模组装上后没有**完全退出游戏重启** | 完全退出再进 |
